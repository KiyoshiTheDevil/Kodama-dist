# Kodama — Distribution

This repository only hosts the public bits required for the app to work:

- `updates/latest.json` — the auto-updater manifest
- `updates/news.json` — the in-app "What's new" feed
- Installer downloads (attached to Releases)

The **source code is private**. Kodama is currently in a **closed beta** —
the installer is shared only with invited testers.
